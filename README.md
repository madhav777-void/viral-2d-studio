# 🎬 2D Motion Graphics & Documentary Explainer Studio

A high-performance 2D motion graphics explainer engine powered by **Google Skia**, **Kokoro Neural TTS**, and **FFmpeg**.
Generates aesthetic Vox / Kurzgesagt / Linear style documentary explainers with floating cards, rolling counters, smooth flow routes, and procedural Foley sound effects.

## 🚀 Running on Hugging Face Spaces (Free 16GB RAM)
Runs natively in Python on Hugging Face Spaces with $0 free CPU/RAM.

### Key Features:
- **Aesthetic 2D Canvas**: Minimalist dot-grid with soft drop shadows and pastel accent tags.
- **Dynamic Storyboarding**: AI directed scenes with smooth camera glides.
- **Dual Mode Audio**: Supports both AI Narrator voice and Silent Foley SFX + Downloadable `.txt` script.
- **Custom Durations**: From 30s quick shorts up to 5 minutes deep-dive documentary explainers.
